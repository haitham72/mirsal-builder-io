# User app review guide

Open **http://127.0.0.1:8770/** — your real history/library. Ports 8797/8798 are test copies.
Use desktop and a phone-width window; repeat the layout checks in **Light and Dark**.
For changes, use a disposable copy. Stop at a shown price; paid runs and sends need a separate decision.

- [ ] **Home / welcome:** counts and artwork look right; film, wording, theme switch and navigation make sense.
- [ ] **Find old work:** reopen a saved Chat, earlier Studio batch and Library pack; refresh and navigate away/back without losing them.
- [ ] **Create / imports:** Chat ↔ Studio, New, photo/video, 2×2 default; explicit 3×3 and duplicate Open existing / Import again choices make sense.
- [ ] **Chat:** conversation, stage/options, selection and plan/price are understandable; long history scrolls normally.
- [ ] **Studio:** Prompt → Stills → Motion → Pack is clear; versions, sheet/sticker views, size/position/reset and frame editor are usable.
- [ ] **Review decisions:** rejected pictures show the reason, Use it anyway and Take it back; technical limits are explained.
- [ ] **Edit / save:** image tools, text, layers, animation/trim and Save work without clipping; Cancel preserves the original.
- [ ] **Library:** search, pack/sticker preview, selection, move, download and Trash/restore are understandable.
- [ ] **Reactions:** Emoji style / Lottie style / Packs work from both entry points; edit, ownership, save-as-new and preview match expectations.
- [ ] **Settings / people / help:** options, health, accounts, Trending, support and FAQ review are clear for the intended role.
- [ ] **Every screen:** phone scrolling, labels, contrast, hover, keyboard Tab/Enter/Escape, menus, loading, empty/error states and recovery feel usable.
- [ ] **Owner decisions:** record wording/pricing/visual verdicts; review paid quality, Telegram and collection delivery separately before authorizing them.

Known defects and engineering limits: [plan.md](plan.md), [backlog](docs/backlog.md) (past audits in git history).
Record: **screen + action + expected/actual + theme/width + screenshot**. Mark each check Pass / Issue / Not checked; do not treat an unchecked item as accepted.
