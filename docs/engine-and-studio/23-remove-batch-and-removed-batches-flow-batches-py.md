# Remove batch and Removed batches (`flow/batches.py`, 2026-10-03, "like remove pack")

<sub>Part of [engine-and-studio.md](../engine-and-studio.md).</sub>

The open batch's header has a **Remove batch** button (`ACT.grm`, `studio-core.js`); its confirm says first what happens. Like *Delete pack* (soft too since 2026-10-03: the pack waits in the library's trash) a Remove destroys nothing: only the purge below deletes for good. `out/G###` (or its labelled `G###-<subject>-<time>`) moves to `out/trash/batches/` under the same folder name (names untouched, rule 9) with a small `G###.meta.json` (when, by whom). The Earlier-batches column then ends in **Removed batches (N)** with **Restore** and **Remove** per batch and one **Remove all (N)** (`live.js` `remHtml`, `ACT.grestore`, `ACT.gpurge`, `ACT.gpurgeall`; empty and hidden for anyone who cannot read the trash). Remove and Remove all are the purge below (files and database rows, for good): Remove confirms once, Remove all asks for the typed `purge N` of the removed **batches only** (`POST /api/trash/purge_all {confirm, kind: "batch"}`, count `purge_batches` in `GET /api/trash`); trashed packs stay for Settings > Trash. Stickers already added to a pack are copies in the library and stay in their packs. A batch with a job in flight is refused in words; a removed number is never reused (`pipeline.next_gid` counts the trash), so a Restore cannot collide; Restore never overwrites. Routes: `docs/api.md`.

**Empty folders are not batches (`pipeline.orphan_batches`, 2026-10-08).** A live `G###` folder with no `result.json` is never a batch: Remove refuses it with 404 (it is not moved through the trash), and the Studio skips it. A zero-file one is stale clutter and goes with `python -m mirsal prune-orphans --apply` (lists without `--apply`; `prune_orphans` deletes only the zero-file ones). A folder that holds files but no `result.json` is an interrupted start: it is reported and never auto-deleted, and a folder an open job still names is kept. `mirsal doctor` reports the count.
