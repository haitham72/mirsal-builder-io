# App-audit fixes (2026-10-20)

What was built from the [2026-10-19 app audit](../uiux_review/app-audit-2026-10-19.md). Each entry names its audit id, where it lives and the test that holds it. Contracts (routes, payloads, stored paths, `data-act` names) are unchanged unless an entry says so.

## Keyboard reach and accessible names

- **UX-03 — sticker tiles work without a mouse.** Pack and Library tiles stay draggable `div`s (drag reorder, marquee, Shift/Ctrl selection unchanged). Their selection box is a `<button class=selbox aria-pressed aria-label="Select {name}">`; the caption is a `<button class=cap>` (Pack: Rename / change emoji; Library: view). The pack tile actions (Preview, Edit, Timeline, Set as cover, Delete) carry the sticker's name in `aria-label`, and `.cell .hov` is hidden by `opacity:0; pointer-events:none` instead of `display:none`, shown on `:hover` **and** `:focus-within`, so Tab reaches them. A keyboard selection toggle puts focus back on the same sticker's box after the grid redraws (`ACT.lsel`). A reaction preset's preview stage (`.rx-stage`) is `role=button tabindex=0`; the shared Enter/Space handler in `studio-panel.js` presses a focused `div[role=button][data-act]` as it already did a sheet-cell `rect`. `tests/js/tile_keyboard.test.js`.
- **UX-04 — every image-editor control has a name.** `editor.js`: the slider/number pairs (`sl`) carry `aria-label` with their unit (`Scale (%)` / `Scale in %`, `Rotate (degrees)`, `Outline width (px)`, Brightness/Contrast/Saturation `%`, Brush size `px`); toggles (`tg`), text, font, text size, Bold, Italic, fill/outline/border colours, border width, emoji size, Zoom, Preview background and Photo cutout are named; the Save sticker labels use `for=`. No `data-inp` or payload changed. `tests/js/editor_labels.test.js`.
- **UX-05 — the frame test card answers the keyboard.** `TESTCARD` (`ui-testcard.js`) stays **non-modal** (no focus trap). `open({focus:true})` moves focus onto the card (the Studio frame card, launched from a button); the Edge card, launched from a slider, leaves focus on the slider. Escape on the card or on its launcher presses its Cancel button (Cancel still drops the test without saving). Closing returns focus to the launcher, or to its redrawn replacement found by `data-act`/`data-g`/`data-i`, only when focus was inside the card. `tests/js/testcard_keyboard.test.js`.

## Identity and ownership

- **UX-06 — real or test workspace.** `GET /api/generations` returns `paths.default` (`store/sync.is_default_out`). When it is false the rail logo carries a small **Test** badge (`.ws-badge`, the `--run` token) and its title says this is not the real `out/`. `tests/js/workspace_badge.test.js`, `tests/test_users.py`.
- **UX-08 — the saved set's heading tells the truth.** `particles.js` `spBody` derives the ownership tag from `SP.set.owner` (on their own / on one sticker / on N stickers), never a hard-coded "on their own". `tests/js/particle_editor.test.js`.
- **UX-11 — recognizable owners.** Manage stickers resolves each `owner[].sticker_id` through the library (`spStickerRef`) to its name, thumbnail and pack; the id is shown only when the sticker is in no pack. `tests/js/particles.test.js`.
