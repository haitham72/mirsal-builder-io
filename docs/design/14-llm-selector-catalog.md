# LLM selector catalog

<sub>Part of [design.md](../design.md).</sub>

The top-right LLM popup groups eligible listed models under Local, Nararouter and OpenAI, using the server catalog. Saved session choices survive reopen; the default cloud model is official OpenAI GPT-5.6 Luna with `high` reasoning. Luna appears only in the OpenAI group; the server alias map displays old router selections as the official id. The same selector supplies Settings and the Studio enhancer through `AIENG`. Image/video model controls stay in the composer; task-stage controls stay in the stage popup.
