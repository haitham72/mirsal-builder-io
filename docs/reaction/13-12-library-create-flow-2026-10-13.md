# 12. Library Create flow (2026-10-13)

<sub>Part of [reaction.md](../reaction.md).</sub>

Library > Reactions > **Create** offers two paths. **Predefined** is the emoji bank (`GET /api/particles/bank`): every token with `finished` (a covering set holds a READY render) or `unclaimed` state, multi-select up to 9, then **Build**: one stand-alone set per emoji (`from_request` with the bank token name), the free procedural sparkle when it has no drawn cells (`default-sprite`, idempotent), and the default animation presented as a preview with the fixed per-emoji motion. **Approve** renders (free) and the build card collapses into the finished list, exactly like a finished reaction; custom sprites remain available later through the set card's Generate more. A finished token rebuilds as a new take. **Stickers** picks one of your stickers and continues in the Studio Particles tab. Nothing here spends without the priced Generate-more step, which stays inside the set card. Reactions made in Reaction effects (`#/reactions`) are listed here too, under "Made in Reaction effects": [the bridge](../library-reactions.md).
