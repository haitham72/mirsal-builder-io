# Diagrams

Excalidraw diagrams of Mirsal Builder at v1.0 (open at excalidraw.com via File → Open). Generated by `build.py` — edit the box/edge lists there and re-run `python3 build.py` (it also validates bindings and overlap).

- `01-overview.excalidraw` — the whole system on one page: screens → FastAPI (adapter for old routes, native routes for stream/tickets/accounts/Trending) → engine/flow/generation/agent/store → outside world, with tickets, accounts and the Telegram admin bot.
- `02-golden-path.excalidraw` — how a sticker pack is made: request → G1 plan → sheet → cuts → G2 stills → G3 video sheet → Kling → frame check → G4 animations → G5 pack → Telegram.
- `03-ai-chat-turn.excalidraw` — what happens on one chat message: resolver → memory → LangGraph nodes → tools → price go-ahead → step trace → /stream (SSE) → reply, polling as the dashed fallback.
- `04-paid-generation.excalidraw` — a paid job end to end: price → go-ahead → your credits (check, reserve; 402 short, owner skips) → ticket first → Higgsfield CLI → batch → settle (real cost, refund on failure) → ledger, with cap, parallel cap and recovery.
- `05-particles.excalidraw` — particles for a sticker: sticker → New version → three equal sources (sticker sprites · AI image · Kling animated) → simulator → Save / Save as new → Render → Add to pack, rows under the sticker, Echo test.
- `06-data.excalidraw` — where things live: `out/` files (batches, library, particles, jobs, chats, tickets, users, requests, trending) mirrored to Postgres tables, Redis as disposable cache, batch groups.
- `07-office.excalidraw` — the office LAN, built end to end: sign up → waiting for approval → Telegram card and Settings > People → approved with 10 credits → paid jobs (reserve/settle/refund) → Request credits → Trending and Use in workflow. Roles: owner everything, admin people, member own work + Trending.

Colours follow `diagram-prompt.md` §3 on every file: blue screens, green engine/flow, purple AI/agent, orange paid providers, grey storage (incl. media, `out/`, Postgres, Redis), yellow human gates, red blocks/checks.
