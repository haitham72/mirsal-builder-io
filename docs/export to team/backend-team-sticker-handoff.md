# Mirsal Sticker Upload — Backend Team Deliverable

## The filename (final, Haitham 2026-10-08)

Every file arrives named as below. Operators fill in **nothing** — all six fields are generated by Mirsal Builder:

```text
{emoji}-{pack_slug}-{multi_action_tag}-{position}-{id}-{date}.{ext}
```

```text
🤣-falcon-laugh_rofl_lmao-s08-G112-20261008.webm
😍-falcon-love_heart_loving-s05-G112-20261008.png
```

| Field | Example | Use in receiving app |
|---|---|---|
| `emoji` | 🤣 | **Tap → every same-emotion sticker across all packs.** Also the assign value: set the actual **Assign to emoji** from this literal glyph (never an alias like `:rofl:`). Index it for interactions/search. |
| `pack_slug` | `falcon` | Pack/menu identity: resolve the pack/category for the **Assign to emoji** flow. |
| `multi_action_tag` | `laugh_rofl_lmao` | **Multi-choice search:** searching `laugh` OR `lmao` shows every sticker carrying that token. Set **Title** from the first token (`laugh`). |
| `position` | `s08` | Source cell inside the sheet (`s01`–`s09`, never renumbered): locate the sticker for faster review. |
| `id` | `G112` | Source generation: traceability into Mirsal's database (the `G###` batch row). |
| `date` | `20261008` | Generation date (UTC `YYYYMMDD`); stable across re-downloads. |
| `ext` | `.webm` / `.png` / `.webp` | Media kind: `.webm` = video, `.png`/`.webp` = static image. |

**Tags:** the tag segment already joins canonical action + aliases with `_`. Index every token separately AND the literal emoji glyph, e.g. `laugh`, `rofl`, `lmao`, `🤣`. Support both text and Unicode emoji queries. A filename alone never replaces the manifest: prefer `manifest.json` (`schema_version` 1) over splitting filenames — `pack_slug` may contain hyphens (`royal-falcon`) and emoji may span several code points.

## Deliverable / acceptance checklist

- Parse filenames right-to-left on the fixed tail (`sNN`, `G###`, date); treat the manifest as authoritative, never fixed-index splitting or alphabetical order.
- Tap-emoji shows cross-pack results for that emotion; search matches any tag token (`laugh` or `lmao` → the same sticker).
- Accept `.png`/`.webp` static and `.webm` video; keep the complete filename.
- Many files share one `pack_slug`, and many share one action/emoji: deduplicate by nothing but the full filename + manifest row.
- Preserve Mirsal-supplied position, generation, and asset metadata unchanged.

**Boundary:** tag vocabulary (the 36-action bank), position numbering, generation ids, dates, revisions, and asset traceability are Mirsal Builder responsibilities — not manual upload-team fields.
