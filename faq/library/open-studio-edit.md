question: How do I open a Library sticker for editing in Studio?
category: library

looks_like: A batch-derived Library sticker offers Edit in Studio and Open in Studio.
---
For a sticker that came from a Studio batch, choose Edit in Studio to edit it or Open in Studio to view its batch. Saving the Studio edit updates that sticker and its copies in packs, rather than creating an unrelated batch. If this does not match what you see, send a screenshot in Help.
